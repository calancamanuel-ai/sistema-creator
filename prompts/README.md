# Istruzioni per Claude

Qui vanno le istruzioni per le parti di ragionamento, una per file, così le attività
programmate le leggono dal repository invece di tenerle nel proprio testo:

- punteggio delle nicchie (fase 1);
- analisi del creator e messaggio (fase 3);
- classificazione delle risposte (fase 4).

Nessun dato personale in questi file.
